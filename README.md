# Discord Bot - Система заявок в семью

Discord бот для обработки заявок на вступление в семью с модальными окнами и полным логированием событий сервера.

## 🎯 Функционал

### 📋 Система заявок
- **Модальное окно** для подачи заявки с полями:
  - Имя и Фамилия
  - Номер паспорта
  - Чем будете полезны в семье
  - OOC Имя
- **Автоматическая нумерация** заявок
- **Изменение никнейма** на формат: "Имя Фамилия | OOC Имя"
- **Автоматическая выдача роли** заявителя при подаче заявки
- **Embed-сообщения** с информацией о заявке
- **Упоминание** подавшего заявку в канале
- **Автоматическое создание панели** заявок при запуске бота


### 📊 Логирование
Все события сервера логируются в указанный канал с **указанием того, кто выполнил действие**:
- Вход/выход участников
- Удаление сообщений (кто удалил + причина)
- Редактирование сообщений
- Баны/разбаны (кто забанил/разбанил + причина)
- Создание/удаление ролей и каналов (кто создал/удалил + причина)
- Изменение ролей участников (кто добавил/удалил роли + причина)
- Изменение никнеймов (кто изменил + причина)
- Голосовая активность
- Обработка заявок

## 🚀 Установка

### 1. Установите зависимости
```bash
pip install -r requirements.txt
```

### 2. Настройте токен бота
1. Скопируйте файл [`.env.example`](.env.example:1) в `.env`:
```bash
cp .env.example .env
```

2. Откройте `.env` и вставьте токен вашего бота:
```
DISCORD_TOKEN=ваш_токен_бота
```


## ⚙️ Запуск бота



```bash
python main.py
```

При запуске бот автоматически:
- Загрузит сохраненные заявки из [`data/applications.json`](data/applications.json:1)
- Очистит канал панели заявок
- Создаст новую панель с кнопкой подачи заявки
- Отправит лог о запуске в канал логов

## 📖 Использование

### Поток работы с заявками

1. **Присоединение к серверу**
   - Новый участник автоматически получает роль заявителя

2. **Подача заявки**
   - Участник нажимает кнопку "📝 Подать заявку в семью"
   - Заполняет модальное окно с данными
   - **Автоматически изменяется никнейм** на формат: "Имя Фамилия | OOC Имя"
   - **Автоматически выдается роль заявителя** (если не была)
   - Заявка отправляется в канал для рассмотрения

3. **Рассмотрение заявки**
   - Модераторы видят заявку в канале
   - Принимают или отклоняют командой

4. **Принятие заявки**
   - Участнику в ЛС приходит уведомление
   - **Выдаются роли принятого**
   - **Снимается роль заявителя**

5. **Отклонение заявки**
   - Участнику в ЛС приходит уведомление с причиной
   - Роли остаются без изменений



## 🗂️ Модули проекта

### [`config/`]
Содержит все настройки бота:
- Токен Discord
- ID каналов (заявки, логи, панель)
- Путь к файлу хранения заявок

### [`utils/`]
Управление хранением заявок:
- Загрузка/сохранение в JSON
- Получение следующего ID заявки
- CRUD операции с заявками

### [`utils/]
Система логирования всех событий в канал логов

### [`utils/`]
Управление ролями и никнеймами:
- Установка никнейма заявителя
- Выдача роли заявителя при подаче заявки
- Выдача ролей принятому при принятии заявки
- Снятие роли заявителя при принятии
- Настройка нового участника

### [`models/`]
Модальное окно с полями для заполнения заявки

### [`models/`]
Кнопка для открытия модального окна

### [`commands/`]
- Команды для работы с заявками


### [`events/`]
События бота:
- Запуск и готовность
- Автоматическая настройка панели заявок

### [`events/`]
События сервера для логирования:
- Участники (вход/выход)
- Сообщения (удаление/редактирование)
- Роли и каналы
- Голосовые каналы

## 🔧 Расширение функционала

Модульная структура позволяет легко добавлять новые возможности:

1. **Новые команды** → создайте файл в `commands/`
2. **Новые события** → создайте файл в `events/`
3. **Новые UI элементы** → создайте файл в `models/`
4. **Новые утилиты** → создайте файл в `utils/`

Примеры расширений:
- Система голосования за заявки
- Автоматическая выдача ролей при принятии
- Статистика по заявкам
- Экспорт данных в Excel/CSV
- Интеграция с базой данных
